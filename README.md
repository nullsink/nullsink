## Why this repository moved

GitHub restricted the maintainer account after its abuse-detection systems flagged unspecified activity for manual review. Support asked how I intended to use GitHub; I replied, but GitHub has not identified the flagged activity or cited a specific Terms of Service provision. As of August 20, 2026, I have received no further response.

Because nullsink needs a reliable development home, I have decided to leave GitHub.

## What comes next

GitLab is an interim home. The longer-term plan is to operate an independent, self-hosted [Forgejo](https://forgejo.org/) instance with a self-hosted Forgejo Runner.
